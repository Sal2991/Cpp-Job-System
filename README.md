# C++ Job System

I'm building a small C++ job system to learn how threads can run tasks at the same time. I want to add features as I go and test how the number of worker threads affects performance.

## Goals

- Create a basic worker pool
- Add a thread-safe job queue
- Handle shutdown cleanly
- Add task results, tests, and benchmarks

This is a work in progress, so some of these features are still planned.
